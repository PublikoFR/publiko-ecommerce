Dropdown over a native `<select>` — accessible and keyboard-friendly.

```jsx
<Select label="Region" placeholder="Choose…" options={['North','South','East','West']} />
<Select label="Crop" options={[{value:'wheat',label:'Wheat'},{value:'corn',label:'Corn'}]} />
```

Sizes: `sm` · `md` · `lg`. Pass `error` for the danger state.
