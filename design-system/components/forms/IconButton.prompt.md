Compact button for a single icon action (toolbars, cards, table rows). Always pass `label` for accessibility.

```jsx
<IconButton label="Edit" variant="ghost"><EditIcon/></IconButton>
<IconButton label="Add" variant="primary" shape="circle"><PlusIcon/></IconButton>
```

Variants: `primary` · `accent` · `secondary` · `ghost`. Sizes: `sm` (32) · `md` (40) · `lg` (48). Shapes: `rounded` · `circle`.
