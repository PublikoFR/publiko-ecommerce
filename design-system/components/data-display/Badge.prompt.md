Small pill for statuses, counts and labels.

```jsx
<Badge tone="success" dot>Active</Badge>
<Badge tone="lime" variant="solid">New</Badge>
<Badge tone="warning">Pending</Badge>
```

Tones: `forest` `lime` `neutral` `success` `warning` `danger` `info`. Variants: `soft` (default) · `solid`. Use `dot` for live-status badges.
